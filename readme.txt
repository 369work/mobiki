== Description ==

Mobiki is a modern WordPress block theme designed with a mobile-first approach and Nordic-inspired aesthetics. Perfect for portfolios, personal blogs, and creative professionals.

= Key Features =

* 📱 **Mobile-First Design** - Optimized for smartphone viewing
* 🎨 **Nordic Color Palette** - Refined colors with a calm, sophisticated feel
* ♿ **Accessibility Ready** - Designed with all users in mind
* ✨ **Beautiful Animations** - Smooth scrolling and fade-in effects
* 🎯 **Full Site Editing** - Complete support for WordPress 6.0+ block editor
* 📐 **Responsive Design** - Beautiful display on all devices
* 🖥️ **Desktop Side Menu** - Fixed navigation menu on the left side for desktop
* 👤 **Profile Card** - Profile display on the right side for desktop


= Layout =

**Desktop Layout:**
- Center: Main content (max-width 600px)
- Left: Navigation menu + Social buttons
- Right: Profile card
- Scroll-to-top button

**Mobile Layout:**
- Profile card directly below hero section
- Fixed footer navigation at bottom
- Scroll-to-top button in bottom-right corner

== Installation ==

1. Go to "Appearance" → "Themes" in the admin panel
2. Click "Add New"
3. Enter "Mobiki" in the search form
4. Install
5. Click Activate
6. Go to the Mbiki settings menu in your admin panel


== Customization ==

= Site Information =
1. Go to 'Settings' > 'General' in WordPress admin
2. Enter your 'Site Title' and 'Tagline'
3. These will automatically appear in the header

= Logo Setup =
1. Go to 'Appearance' > 'Customize' > 'Site Identity'
2. Click 'Select Logo' to upload your logo image
3. Recommended size: 400×100px (transparent PNG recommended)

= Menu Setup =
1. Create a new menu from 'Appearance' > 'Menus'
2. Add menu items (pages, custom links, etc.)
3. Assign menu to locations:
   - Primary Menu - Desktop side menu
   - Mobile Menu - Mobile footer navigation
   - Footer Menu - Footer (optional)


= Profile Settings =
After installing the theme, please configure your profile settings:
1. Go to 'Appearance' > 'Mobiki Settings' in WordPress admin
2. Set up your profile information
3. Save your changes

= Profile Card Customization =
1. Go to 'Appearance' > 'Editor' > 'Template Parts' > 'side-profile'
2. Edit emoji, text, and status
3. Save your changes


= Social Buttons Customization =
1. Go to 'Appearance' > 'Editor' > 'Template Parts' > 'side-menu'
2. Update social button URLs
3. Remove unused social buttons as needed


= Color Theme Changes =
Edit the `theme.json` file to change the site-wide color palette.

== Troubleshooting ==

= Styles not displaying =
1. Clear browser cache
2. Open 'Appearance' > 'Customize' in WordPress admin and save
3. If using cache plugins, clear the cache

= Menu not displaying =
1. Verify menu is created in 'Appearance' > 'Menus'
2. Check that menu location is correctly assigned
3. Try reactivating the theme

= Mobile layout issues =
1. Clear browser cache
2. Verify viewport settings are correct
3. Confirm CSS files are loading properly
